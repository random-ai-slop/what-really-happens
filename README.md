# What Really Happens · 到底发生了什么

Two one-take films about a C hello world, made to be watched in the browser. Each one plays live from its own animation engine, so you can pause on any frame and walk around inside it. English narration, English and Chinese captions.

两部关于 C 语言 hello world 的一镜到底短片，在浏览器里观看。画面由动画引擎实时绘制，随时暂停，就能走进画面四处看看。英文旁白，中英文字幕。

## Watching · 观看

- **Play / pause:** click the Run button on the opening frame, or press `space` (`K`).
- **Seek:** drag the bar, or use `←` `→` (5 s), `J` `L` (10 s), `Shift` + `←` `→` (chapters).
- **Captions:** `C` cycles English · English + 中文 · 中文 · off.
- **Explore:** pause, then drag to move the camera; scroll or pinch to move in and out; right-drag or `Shift`-drag to tilt. `R` or `Esc` goes back to the shot.
- **Notes:** while paused, a small `+` beside an object opens a note about it.
- `F` fullscreen, `?` all controls.

- **播放 / 暂停：** 点开场画面里的 Run 按钮，或按空格键（`K`）。
- **跳转：** 拖动进度条，或用 `←` `→`（5 秒）、`J` `L`（10 秒）、`Shift` + `←` `→`（上一章 / 下一章）。
- **字幕：** 按 `C` 在 English · English + 中文 · 中文 · 关闭 之间切换。
- **四处看看：** 暂停后拖动画面移动镜头；滚轮或双指缩放推近拉远；右键拖动或按住 `Shift` 拖动倾斜画面。`R` 或 `Esc` 回到原镜头。
- **注释：** 暂停时，物体旁的小 `+` 号会打开关于它的注释。
- `F` 全屏，`?` 查看全部按键。
