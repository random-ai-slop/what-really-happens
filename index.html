Two one-take films · 两部一镜到底的短片

What Really Happens

到底发生了什么

One C hello world, followed all the way down: what has to happen before the Run button means anything, and what happens when you click it. Each film plays live in your browser, so you can pause on any frame and walk around inside it.

跟着一个 C 语言的 hello world 一路往下走：Run 按钮能起作用之前，要先发生些什么；点下它之后，又发生了什么。两部片子都在浏览器里实时播放，随时暂停，就能走进画面四处看看。

What Really Happens When You Click Run

点下 Run 的那一瞬间，到底发生了什么？

From the Run button down to silicon, and back up as light.

从 Run 按钮一路下到硅片，再化作光回到屏幕上。

Episode 2第二集7:32

What Really Happens Before You Click Run

点下 Run 之前，到底发生了什么？

Power, firmware, a kernel, 77,000 packets, one keystroke and one save, all before Run means anything.

通电、固件、内核、7.7 万个数据包、一次按键、一次保存：都发生在 Run 起作用之前。

Watching

Click Run or press space to play, drag the bar to seek, C cycles captions. Pause, then drag to look around; a small + beside an object opens a note.

点 Run 或按空格键播放，拖动进度条跳转，按 C 切换字幕。暂停后拖动画面就能四处看看，物体旁的小 + 号会打开注释。
